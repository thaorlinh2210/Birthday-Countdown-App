# 🎂 Birthday Countdown App 

A SwiftUI application that allows users to add, edit, and track upcoming birthdays.

## 🚀 Features
- ✅ Add birthdays with a name and date  
- ✅ Edit existing birthdays  
- ✅ Automatically calculates days until the next birthday  
- ✅ Simple and clean SwiftUI interface  

---

## 📋 Requirements
- **Xcode 15+**
- **iOS 17+**
- **Swift 5.9+**

---

## 🛠 Installation & Setup

### 1️⃣ Clone the Repository
If you're using Git, run:

git clone https://github.com/your-repo/birthday-countdown.git
cd birthday-countdown

### 2️⃣ Open the Project  
- Open **BirthdayCountdown.xcodeproj** or **.xcworkspace** in Xcode.  

### 3️⃣ Run the App  
- Select a **simulator** or connect an **iPhone**.  
- Press **Cmd + R** or click ▶️ **Run** in Xcode.
